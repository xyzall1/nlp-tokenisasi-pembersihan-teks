# Tokenisasi dan Pembersihan Teks (NLP)

Proyek ini berisi **preprocessing teks** untuk Natural Language Processing (NLP): tokenisasi kalimat & kata, pembersihan teks, penghapusan stopwords, stemming, dan lemmatization.

## 📌 Deskripsi

Notebook menganalisis paragraf tentang **populisme di Amerika Serikat dan Eropa abad ke-21**. Langkah yang dilakukan:

1. **Tokenisasi kalimat** (sentence tokenization) dengan NLTK `sent_tokenize`
2. **Tokenisasi kata** (word tokenization) dengan NLTK `word_tokenize`
3. **Pembersihan teks**: lowercasing, hapus angka, hapus tanda baca, hapus spasi berlebih
4. **Penghapusan stopwords** (bahasa Inggris)
5. **Stemming** (Porter Stemmer)
6. **Lemmatization** (WordNet)
7. **Analisis frekuensi kata**

## 🛠️ Requirements

- Python 3.x
- NLTK (`pip install nltk`)
- NLTK data: `punkt`, `punkt_tab`, `stopwords`, `wordnet` (akan di-download otomatis di notebook)
